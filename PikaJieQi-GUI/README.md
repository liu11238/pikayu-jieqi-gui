# PikaJieQi 暗棋 GUI

## 启动

在 Windows 中双击 `启动GUI.bat`。该脚本会优先激活已有的 `autogui` Conda 环境。

也可以在 Anaconda Prompt 中手动运行：

```text
conda activate autogui
cd /d D:\code\git\pikayu\PikaJieQi-GUI
python app.py
```

程序默认寻找 `..\Pikafish-jieqi-old\src\PikaJieQi.exe`。找不到时在“设置引擎”中选择 exe。

## 功能

- 重置到暗棋初始局面；“编辑局面”可直接输入完整暗棋 FEN。
- 点击棋盘输入双方实际走法。界面会显示当前行棋方，红黑双方每次输入合法走法后自动轮换；推荐走法只显示在评分栏、状态栏和棋盘绿色箭头上，不会自动落子。
- 点击“开始持续分析”后使用 `go infinite` 持续搜索，评分栏实时显示搜索层数、评分和完整棋谱（PV）；随着深度增加，当前最优解会实时更新。棋盘只绘制当前局面的第一步箭头，不绘制后续主变化。
- “强制变招”会把当前推荐走法加入本局面临时禁用列表，并重新分析剩余选择；可以连续点击强制变招，使用“清除禁用”恢复全部选择。禁用列表不会写入棋谱，走棋、撤销、重做、重置或编辑局面后自动清空。
- 启动或重启引擎后，GUI 会自动探测 `banmoves` 扩展。支持时使用 `position` 后的 `banmoves`；不支持或运行中未生效时自动回退到标准 UCI `searchmoves` 白名单。
- 红方或黑方走子后，旧箭头会立即消失，并基于新局面重新分析；若之前正在持续分析，会自动继续分析新局面。
- 吃到 `X/x` 或移动暗子时，会弹出棋种按钮选择窗口；选择“未知（不输入）”即可保留未知状态。
- “翻转棋盘 180°”只改变显示视角和鼠标点击映射，不改变内部局面、走法坐标或引擎分析结果。
- 撤销、重做、搜索深度、Threads、Hash、MultiPV 和引擎路径设置。
- 评分来自 UCI `info ... score`，以当前行棋方为引擎视角；`cp` 为厘兵单位。

说明：当前 GUI 通过现有标准 UCI 驱动引擎，暗子真实信息只在 GUI 输入和引擎走法后缀中传递，不会自动把推荐走法写入棋局。
